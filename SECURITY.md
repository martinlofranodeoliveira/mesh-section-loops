# Security Policy

## Supported Versions

Only the latest release on the `main` branch receives security updates.

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |
| < 0.1   | :x:                |

## Reporting a Vulnerability

We take the security of `mesh-section-loops` seriously. If you discover a security vulnerability, please report it responsibly:

1. **GitHub Private Vulnerability Reporting**: Open a draft security advisory via [GitHub Private Vulnerability Reporting](https://github.com/martinlofranodeoliveira/mesh-section-loops/security/advisories/new).
2. **Direct Email**: If private reporting is unavailable, email `security@lofranotecnologia.com.br` with full technical details, proof of concept, and reproduction steps.

Please do not open public GitHub issues or discussions for undisclosed security vulnerabilities.

### Response Commitment

- **Acknowledgment**: Within 48 hours of initial report.
- **Triage & Assessment**: Within 5 business days with preliminary findings.
- **Fix & Advisory**: Coordinated public disclosure following remediation release.
